四、数据供应商路由

国内数据源 · 四大境内源 ⭐

  • BaoStock — 免费无限流，专为 A 股设计，最稳定
  • AKShare 腾讯 — stock_zh_a_hist_tx，限流少
  • AKShare 新浪 — stock_zh_a_daily，较稳定
  • AKShare 东方财富 — stock_zh_a_hist，数据最全但易限流
  • 技术指标计算（RSI/MACD/均线）
  • 四源自动回退，全部落空记为无数据（不访 Yahoo）

核心行情 · core_stock_apis

  • akshare — A 股优先（东财/腾讯/新浪）
  • yfinance — Yahoo Finance OHLCV（美股/海外）
  • 默认链：akshare,yfinance

技术指标 · technical_indicators

  • akshare — A 股指标优先；yfinance 覆盖美股
  • 默认链：akshare,yfinance
  • get_verified_market_snapshot 验证快照

基本面 · fundamental_data

  • sec_edgar — SEC 财报（按 filed date，point-in-time）
  • akshare — A 股财报
  • yfinance — 资产负债表 / 现金流 / 利润表（美股）
  • alpha_vantage — 综合基本面数据
  • 默认链：sec_edgar,akshare,yfinance

新闻数据 · news_data

  • akshare — A 股新闻优先
  • yfinance — 公司新闻 + 全球宏观新闻（美股）
  • 默认链：akshare,yfinance
  • insider_transactions — 内部人交易

宏观经济 · macro_data

  • FRED — 美联储经济数据
  • CPI / PCE / 失业率 / 联邦基金利率
  • 欧元区指标镜像系列
  • 可选分类：失败不中断运行
  • A 股批量分析默认 "none"：零请求，不付连接超时

预测市场 · prediction_markets

  • Polymarket — 市场隐含概率（美股叙事事件）
  • sse_option — 上交所期权隐含概率（A 股批量分析默认）
  • 可选分类：失败降级为哨兵，不中断运行
  • A 股批量分析配 "sse_option"；配 "none" 则零请求跳过

社交情绪 · (内置于 Sentiment Analyst)

  • Reddit — 投资社区讨论
  • StockTwits — 交易者情绪
  • Jev 筛选（可选）— TypeSafe 过滤无关帖子
  • A 股（.SS/.SZ）全部跳过：两个源均不收录

路由机制 · router.py

  • route_to_vendor() — 按配置链路由
  • tool_vendors 优先于 data_vendors
  • 不静默跳转到未配置的供应商
  • NO_DATA_AVAILABLE / DATA_UNAVAILABLE 哨兵
  • 可选类别配 "none" → 立即返回哨兵，不发请求
  • 分段超时（连接 3s）+ 连不上的主机 10 分钟内不再请求

七、关键设计决策

Point-in-Time 防护

  • date_window.py 确保历史运行不读取未来数据
  • SEC EDGAR 按 filed date 提供财报
  • 记忆日志按 resolved date 过滤教训
  • 回测评分只使用分析日之后的价格

检查点恢复

  • SQLite 持久化每个节点状态
  • 签名机制保证配置变更时重建
  • crash 后从最后成功节点恢复
  • 成功后自动清除检查点

记忆隔离

  • 实盘运行 → ~/.tradingagents/memory/
  • 回测运行 → results_dir/backtest/ 独立日志
  • 回测不污染实盘记忆
  • 跨 ticker 经验教训自动分享

全球市场支持

  • ticker 后缀自动识别区域（.HK / .T / .SS ...）
  • benchmark_map 自动匹配区域基准指数
  • 支持股票 + 加密货币两种资产模式
  • 多时区日期对齐处理

五步筛选漏斗

  • 第 1 步：股票池 - AKShare 全 A 股 ~5200 只
  • 第 2 步：基础过滤 - 剔除 ST/科创板/北交所
  • 第 3 步：资金面 - 主力净流入>0 取前 100（盘前降级为最近一个交易日）
  • 第 4 步：消息面 - 近一周利好板块
  • 第 5 步：技术面 - RSI 30-65/MA20/MACD/量比
  • ⭐ 潜力评分：满分 100，按分降序排序

CLI 集成

  • .\.venv\Scripts\activate.bat 激活虚拟环境
  • tradingagents screener --top 3 --workers 1
  • --date YYYY-MM-DD 指定分析日期
  • --save/--no-save 控制报告保存（--html 附带完整报告 HTML，默认开）
  • --max-candidates N 深度分析上限（默认 50，按潜力评分截断）
  • --yes 跳过交互确认（无人值守）
