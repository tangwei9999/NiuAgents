# A 股选股器 (Stock Screener)

自动从 A 股全市场扫描、筛选、分析并推荐股票的智能选股工具。

## 功能特点

- **五步筛选漏斗**：股票池 → 基础过滤 → 资金面前 100 → 消息面利好板块 → 技术面筛选，逐级收敛到几十只潜力股
- **交互确认**：筛选完成后打印潜力股列表（含潜力评分），由你决定是否进入深度分析；`--yes` 跳过确认（定时/无人值守场景）
- **多智能体深度分析**：复用 TradingAgents 的多智能体分析引擎，对潜力股逐一深度分析
- **综合评分**：多维度评分（LLM 评级 40% + 技术面 30% + 资金面 20% + 动量 10%）
- **交易点位建议**：Top N 每只股票输出一行阻力位、支撑位、建议买入价、建议卖出价
- **自动留档**：Top N 每只一份评分摘要，外加一份与 CLI 同格式的完整报告树（分析师到风控全正文，`complete_report.md`；`--html` 时再配一页 `complete_report.html`）
- **多源数据回退**：AKShare（东方财富）> BaoStock > 内置股票池，确保数据可用

## 数据源优先级

**股票池 / 资金流 / 板块 / 新闻**（AKShare，无需 API Key）：

| 优先级 | 数据源 | 接口 | 说明 |
|--------|--------|------|------|
| 1 | **AKShare 东方财富** | `stock_zh_a_spot_em` 等 | 全 A 股 5000+，数据最全 |
| 2 | **BaoStock** | `query_all_stock` | 免费无限流，备用 |
| 3 | **内置股票池** | 硬编码 | 核心蓝筹，永不失败 |

**个股技术指标**（K 线数据，`data_source.py`）：

| 优先级 | 数据源 | 稳定性 |
|--------|--------|--------|
| 1 | BaoStock | ⭐⭐⭐⭐⭐ 免费无限流 |
| 2 | AKShare 腾讯 | ⭐⭐⭐⭐ 限流少 |
| 3 | AKShare 新浪 | ⭐⭐⭐⭐ 较稳定 |
| 4 | AKShare 东方财富 | ⭐⭐⭐ 数据全但易限流 |

四个都是境内源。这里原本还有第五档 Yahoo：已删。海外源不可达时只会返回 `None`，
到手里就成了“这只票没有数据”而丢候选，与它本身不可达分不开；而且直连 Yahoo
在境内网络下每只失败票都要白付重试与超时的等待。取不到指标就记为无数据。

**交易点位的 K 线**（`price_levels.py`，与上表是两个独立入口）：

| 优先级 | 数据源 | 说明 |
|--------|--------|------|
| 1 | AKShare 东方财富 | `stock_zh_a_hist(adjust="qfq")`，前复权且保留完整高低区间 |
| 2 | AKShare 腾讯 | 限流少于东财 |
| 3 | AKShare 新浪 | `stock_zh_a_daily`，全量历史后截近窗口 |
| 4 | BaoStock | `adjustflag="2"`（前复权） |

这条链把东财放首位，是因为点位要的是最高/最低价的完整振幅；上表把 BaoStock
放首位要的是批量取指标的稳定性。两处都不会回退到 Yahoo。

## 快速开始

### 1. 激活虚拟环境

```powershell
# 进入项目根目录（你 clone 下来的 NiuAgents 目录，路径按实际替换）
cd <项目根目录>
.\.venv\Scripts\activate.bat
```

### 2. 运行选股器（CLI 推荐）

```powershell
# 推荐 3 只股票（默认），建议 --workers 1 避免限流
tradingagents screener --top 3 --workers 1

# 推荐 5 只股票
tradingagents screener --top 5 --workers 1

# 指定分析日期
tradingagents screener --top 3 --date 2026-11-09

# 不保存报告
tradingagents screener --top 3 --no-save

# 无人值守：跳过深度分析前的确认（没有 tty 时不会卡在提问上）
tradingagents screener --top 3 --workers 1 --yes
```

也可以用模块方式运行：

```powershell
python -m tradingagents.screener.a_stock_screener --top 3 --workers 1
```

### 3. 查看报告

报告保存在 `~/.tradingagents/logs/screener/<日期>/` 目录下：每股一份 `topN_代码_名称.md`
评分摘要，以及一个以代码命名的子目录，里面是框架自己写的 `complete_report.md`；
开了 `--html` 时，同目录还有一页 `complete_report.html`。

## 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--top N` | 推荐股票数量 | 3 |
| `--workers N` | 最大并发分析数（建议 1） | 3 |
| `--date YYYY-MM-DD` | 分析日期 | 今天 |
| `--save/--no-save` | 是否保存报告（摘要 + 每股完整报告树） | 保存 |
| `--html/--no-html` | 完整报告是否再渲一页 HTML | 生成 |
| `--yes` | 跳过深度分析前的确认 | 询问 |
| `--max-candidates N` | 深度分析的潜力股上限，按潜力评分降序取前 N（以前收了不生效，现已真截断） | 50 |

## 工作流程（五步筛选漏斗 + 交互确认）

```
第 1 步：获取股票池（AKShare 全 A 股 ~5200 只）
   ↓
第 2 步：基础过滤（剔除 ST、科创板 688、北交所 8/4，保留主板/中小板/创业板）
   ↓
第 3 步：资金面预筛选（主力净流入 > 0，取前 100 只；盘前自动改用最近交易日数据）
   ↓
第 4 步：消息面筛选（资金流入前 20 板块评估近 7 天利好，保留属于利好板块的股票）
   ↓
第 5 步：技术指标过滤（RSI 30-65、股价>MA20、MACD 金叉、量比≥0.8）→ 几十只潜力股
   ↓
🎯 打印潜力股列表（按潜力评分降序），询问是否继续深度分析（`--yes` 时不问）
   ├─ 选「否」→ 保留潜力股列表，结束
   └─ 选「是」↓
第 6 步：批量深度分析（TradingAgents 多智能体，每只约 3-5 分钟）
   ↓
第 7 步：综合评分排序
   ↓
🏆 输出最终推荐表格（股票代码、股票名称、上涨潜力分数、综合评级）
   ↓
📌 交易点位建议（每只一行：股票代码/名称/阻力位/支撑位/建议买入价/建议卖出价）
   ↓
第 8 步：保存 Top N 报告
```

## 两阶段评分

### 第一阶段：潜力评分（快速筛选，各项累加满分 115）

| 因素 | 评分 | 说明 |
|------|------|------|
| RSI 30-50（低位） | +30 | 还没大涨，启动初期（50-60 得 +20，其余 +10） |
| 刚突破 MA20（<5%） | +25 | 早期上升趋势确认 |
| 离 MA60 近（<10%） | +20 | 长期趋势向好 |
| 主力净流入 > 1000 万 | +15 | 大资金认可（净流入 > 0 得 +10） |
| 板块消息面利好 | +15 | 近期有催化剂（评分 ≥30 得 +10，>0 得 +5） |
| MACD 金叉 | +10 | 技术面确认 |

### 第二阶段：综合评分（深度分析后排序，满分 100）

四个维度各自归一化到 0-100，再按下面的权重加权，所以总分仍是百分制：

| 维度 | 权重 | 说明 |
|------|------|------|
| LLM 评级 | 40% | 多智能体分析引擎的 5 级评级 |
| 技术面 | 30% | RSI、MACD、均线系统 |
| 资金面 | 20% | 主力净流入、量比 |
| 动量 | 10% | 价格趋势、突破情况 |

## 筛选条件

### 基础过滤（第 2 步）
- 剔除 ST/*ST 股票
- 剔除科创板（688 开头）和北交所（8/4 开头）
- 只保留主板（600/601/603/605、000/001）、中小板（002/003）、创业板（300/301）

### 资金面预筛选（第 3 步）
- 主力净流入 > 0（机构资金买入），取净流入排名前 100 只
- **盘前 / 非交易时段自动降级**：东财“今日”资金流在开盘前数值全为空，此时改用
  **最近一个已完成交易日**的主力净流入（先用近 5 日排行取活跃候选池，再并发精查
  每只股票的最近交易日净流入），不会因“没有股票满足资金面条件”而中断
- 第 5 步的多因子资金面条件与潜力评分同样使用该最近交易日数据（结果缓存复用）

### 消息面筛选（第 4 步）
- 取资金流入前 20 的行业板块（盘前同样降级为近 5 日板块资金流）
- 逐板块抓取代表股近 7 天新闻，命中利好关键词（利好/增长/突破/政策支持/订单等）评分 ≥ 30 视为利好板块
- 保留属于利好板块的股票

### 技术面筛选（第 5 步）
- RSI 30-65（早期上升趋势，避免追高）
- 股价在 20 日均线上方
- MACD 金叉
- 量比 ≥ 0.8

### 交易点位口径（最终推荐的 📌 输出）

| 字段 | 计算方式 |
|------|----------|
| 支撑位 | 近 20 个交易日**最低价**的 10% 分位（避开单根长下影） |
| 阻力位 | 近 20 个交易日**最高价**的 90% 分位（避开单根长上影） |
| 建议买入价 | 支撑位上方 2%，且不低于现价 8%；若贴现价太近（回调不足 2%）则取现价下方 3% |
| 建议卖出价 | 阻力位下方 2%，且不高于现价 12%；若获利空间不足 3% 则取现价上方 3% |

输出形如（一只股票一行）：

```
股票代码：300624，股票名称：万兴科技，阻力位：53.32，支撑位：43.78，建议买入价：48.13，建议卖出价：53.88
```

K 线取数按东财（前复权）→ 腾讯 → 新浪 → BaoStock 回退，不访 Yahoo；
某个源不可用时自动下一个，均失败则该只输出 `N/A`，不影响推荐结果本身。

## 注意事项

1. **耗时**：第 1-5 步筛选约 2-3 分钟；深度分析每只股票约 3-5 分钟（交互确认时选「否」可只看潜力股列表；无人值守用 `--yes`）
2. **API 限流**：建议 `--workers 1` 避免数据源限流
3. **数据质量**：AKShare 东方财富数据最全但易限流，系统自动回退到 BaoStock；筛选与深度分析两个阶段都只走境内源，不拿 Yahoo 兜底（分层规则：只有 `dataflows/` 允许 `import yfinance`，由 `tests/test_layering.py` 看住），且东财偶发限流返回空数据时会自动重试一次
4. **海外源与超时**：深度分析默认关掉海外宏观源 FRED（美国宏观），`data_vendors` 里置为 `"none"`，工具直接返回「不可用」哨兵，一次请求也不发。Polymarket（美国事件预测市场）没有国内一比一对应物 —— 国内无公开的事件预测市场，QVIX 期权波动率指数与 chinascope 情绪指数实测均不可达 —— 因此 `prediction_markets` 换为 `sse_option`：由上交所 ETF 期权链反解「到期收盘高于／低于某价位」的风险中性隐含概率与隐含前向价，实测单次 0.05-0.11s、按日缓存，与 Polymarket 同属「市场对前瞻事件的定价」这一形态，但只覆盖宽基指数到期价位（个股与行业事件会明确返回未被定价），且含波动率溢价、把下行尾部定得比实际更重。话题关键词含行业/风格词（中英文均可，如「半导体」或 semiconductor）会加挂对应宽基的期权板；问到期权链无法定价的事件（降息、关税、大选等）时，报告会在数字**之前**先声明该事件未被定价，而不是把它放在表格脚注里。A 股标的也不再抓取 StockTwits / Reddit（不收录 A 股）与 TypeSafe 筛查。其余海外端点采用分段超时（连接 3s / 读取 10-20s），且某个主机连接失败后会在 10 分钟内被跳过（首次付一次 3s，后续 0s），不再每只股票每个话题重复等待。可用 `TRADINGAGENTS_HOST_BLOCK_COOLDOWN`（秒）调整该时长，`0` 表示不跳过；需要海外源时把 `macro_data` / `prediction_markets` 改回 `"fred"` / `"polymarket"` 即可，美股链路本来就仍走 `polymarket`
5. **第三方库自己的超时**：上面那套分段超时只管住本项目发出的请求，两个国内源库自己发请求，需单独限。AKShare 库内全局默认是（连接 10s / 读取 60s）且失败内部重试 3 次，一个卡住的东财接口最坏可耗近 3 分钟，现已在 vendor 导入时收紧为（5s / 20s）（可改 `TRADINGAGENTS_AKSHARE_TIMEOUT=连接,读取`）；BaoStock 的 SDK 直接建裸 socket 并在 `while True` 里 recv，**不设超时也不会放弃**，现每次交互给该 socket 上 15s 限时（可改 `TRADINGAGENTS_RAW_SOCKET_TIMEOUT`），卡住时只付 15s 就交给下一个数据源。全市场快照（共 59 页）实测仍正常返回，未被收紧误伤
6. **盘前运行**：资金面与板块热度均自动改用最近一个已完成交易日的数据，输出会标注实际使用的数据窗口（如“改用最近交易日（2026-11-09）的主力净流入”）；因需额外一次近 5 日排行 + 并发精查，第 3 步耗时约 1 分钟
7. **免责声明**：点位为波段高低点的机械计算结果，仅供研究参考，不构成投资建议
