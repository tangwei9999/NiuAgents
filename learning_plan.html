TradingAgents 从 0 到 1 学习计划

6 个阶段，由浅入深掌握多智能体量化交易框架。勾选已完成步骤，进度自动保存。

学习建议

  • 前置知识：Python 基础、对 LLM / AI Agent 有初步了解即可
  • 实践优先：每个阶段都建议动手跑代码，不要只看文档
  • 环境准备：Python 3.11+、一个 LLM API Key（OpenAI / Google / Anthropic 任选）
  • 阅读顺序：先读 README → 再读架构图 → 然后按阶段推进
  • 遇到问题：查看 tests/ 目录下的测试用例，它们是最好的使用示例

选股器采用五步筛选漏斗：股票池→基础过滤（剔除 ST/科创板/北交所）→资金面前 100→消息面利好板块→技术面筛选，找出几十只潜力股；交互确认后深度分析推荐 Top 3。技术指标数据源：BaoStock > AKShare 腾讯 > AKShare 新浪 > AKShare 东方财富（全境内链，不访 Yahoo）。

⭐.2 运行第一次选股
先执行 .\.venv\Scripts\activate.bat 激活虚拟环境，然后执行 tradingagents screener --top 3 --workers 1 运行选股器。观察控制台的五步漏斗：股票池→基础过滤→资金面前 100→消息面利好板块→技术面筛选，随后打印潜力股列表并询问是否继续（选「否」结束，选「是」进入深度分析，--yes 可跳过提问），深度分析完成后以表格输出最终推荐 Top 3（股票代码、名称、上涨潜力分数、综合评级），并附每只股票一行的交易点位建议（阻力位、支撑位、建议买入价、建议卖出价）；每只推荐股的完整报告树落盘到 ~/.tradingagents/logs/screener/<date>/（分节 md + complete_report.md/html）。
