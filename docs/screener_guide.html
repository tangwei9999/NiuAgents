TradingAgents 内置选股器

A股智能选股实战指南 — 从全市场 5000+ 只股票中自动推荐 Top 3

⭐ 新功能 · 无需提供候选股票池

重要声明

  • 本项目仅供研究，不构成投资建议。官方明确声明："It is not intended as financial, investment, or trading advice."
  • 系统输出的是 5 级评级（Buy/Overweight/Hold/Underweight/Sell）和综合评分，不直接给出具体价格点位。
  • 卖出点位需要结合技术分析师输出的 RSI / MACD / 布林带 等指标自行判断。
  • 选股器数据来自 AKShare 多数据源（东方财富/腾讯/新浪）+ BaoStock，覆盖全 A 股主板和创业板，支持多源回退；不访问 Yahoo。
  • LLM 输出有随机性，同一只股票跑两次结果可能不同。

🎯 核心功能：一键智能选股

  • 全市场覆盖：从 A 股全市场 5000+ 只股票中智能筛选，不再局限于固定股票池
  • AKShare 数据源集成：AKShare（东财）＞ BaoStock ＞ 内置股票池，国内数据源优先，限流时自动回退
  • 多维度分析：消息面、技术面、资金面、基本面全方位分析
  • 多智能体深度分析：复用 TradingAgents 的 11 个 LLM 智能体分析引擎
  • 综合评分排序：LLM 评级 40% + 技术面 30% + 资金面 20% + 动量 10%
  • 交易点位建议：最终推荐每只一行输出阻力位、支撑位、建议买入价、建议卖出价
  • 自动报告生成：Markdown/HTML 格式的详细分析报告

🌅 盘前运行（09:30 之前）

东方财富的「今日」个股与板块资金流在开盘前数值全部为空，旧版本会因此筛出 0 只并提示「没有股票满足资金面条件」而中断。现在会自动降级为最近一个已完成交易日的资金流：先用近 5 日排行取活跃候选池，再并发精查每只股票的最近交易日主力净流入，输出会标注实际使用的数据窗口（如“改用最近交易日（2026-11-09）的主力净流入”）。第 5 步的资金面条件与潜力评分同样使用该数据，盘中运行时行为不变。

📌 交易点位建议（最终推荐输出）

排名确定后，每只股票额外输出一行交易点位，形如： 股票代码：300624，股票名称：万兴科技，阻力位：53.32，支撑位：43.78，建议买入价：48.13，建议卖出价：53.88。 口径：支撑/阻力位取近 20 个交易日最低价/最高价的 10% / 90% 分位（避开单根异常影线把交易位推到现价 ±20% 以外）； 建议买入价为支撑上方 2%，且不低于现价 8%；建议卖出价为阻力下方 2%，且不高于现价 12%； 当现价已贴近或突破压力区（获利空间不足 3%）时，目标位顺延为现价上方 3%。 K 线按东财（前复权）→ 腾讯 → 新浪 → BaoStock 回退，不访 Yahoo；取数失败时该只输出 N/A，不影响推荐结果。

运行时间预估

第 1-5 步筛选漏斗约需 2-3 分钟（以批量计算技术指标为主）。深度分析阶段每只股票需要 3-5 分钟——若交互确认时选择「否」，总耗时仅需几分钟即可拿到潜力股列表。

⏱️ 为什么不再刷海外超时

以前深度分析阶段会反复出现 gamma-api.polymarket.com timed out. (connect timeout=30) 与 Reddit RSS 超时：这些是消息面/情绪面分析师的海外补充源，国内网络下永远连不上，却要为每个话题付一整个 30 秒，日志也被 WARNING 刷满。现在四层收敛：

① A 股批量分析把 macro_data 配为 "none"，该工具零请求零耗时；② prediction_markets 改配为国内可达的 "sse_option"，由上交所 ETF 期权链反解“到期收盘高于／低于某价位”的隐含概率，单次 0.05-0.11s、按日缓存；③ A 股标的跳过 StockTwits / Reddit 抓取与 TypeSafe 筛查（它们不收录 A 股）；④ 其余海外端点改为分段超时（连接 3s / 读取 10-20s），并在连接失败后于 10 分钟内跳过该主机。实测：不可达主机首次 3.0s、后续 0.000s（以前每话题 30s）。时长可用 TRADINGAGENTS_HOST_BLOCK_COOLDOWN（秒，0 为不跳过）调整；确实需要海外源时，把两个配置改回 "fred" / "polymarket" 即可。

期权隐含概率不是预测，也不是国内版 Polymarket：国内没有公开的事件预测市场（QVIX 期权波动率指数、chinascope 情绪指数实测均已不可达），期权链是目前唯一同形态上“市场对前瞻事件定价”、且国内网络可达的东西。它只定价宽基指数的到期价位，风险中性概率含波动率溢价、会把下行尾部定得偏重；问“Fed 降息”这类话题时它会明确回答未被定价，而不是拿中国指数概率充数。

国内源库自己发请求，不归上面的超时管，所以另加了两个预算：AKShare 库内默认（连接 10s / 读取 60s）且失败内部重试 3 次，一个卡住的东财接口最坏能耗近 3 分钟，现已收紧为（5s / 20s）（TRADINGAGENTS_AKSHARE_TIMEOUT=连接,读取）；BaoStock 的 SDK 直建裸 socket 并在 while True 里 recv，不设超时也不会放弃，卡住时会让整个选股器停摆，现每次交互给该 socket 上 15s 限时（TRADINGAGENTS_RAW_SOCKET_TIMEOUT），到点就交给下一个数据源。收紧后实测：8 个分析师工具合计 1.88s，全市场 59 页快照仍正常返回。
