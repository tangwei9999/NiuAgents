NiuAgents A股实战指南

从安装到运行，使用内置选股器自动分析 A 股并选出 3 只推荐买入股票 + 卖出点位

重要声明

  • 本项目仅供研究，不构成投资建议。官方明确声明："It is not intended as financial, investment, or trading advice."
  • 分析引擎输出 5 级评级（Buy/Overweight/Hold/Underweight/Sell）；交易员在能给出时会附上入场价 / 止损位 / 仓位建议。
  • 选股器的最终推荐另有阻力位 / 支撑位 / 建议买入价 / 建议卖出价，那是波段高低点的机械计算结果；卖出时机仍需结合技术分析师输出的 RSI / MACD / 布林带 自行判断，本指南会教你怎么读。
  • A 股数据来自 四大境内源（BaoStock > AKShare 腾讯 > AKShare 新浪 > AKShare 东财），覆盖全 A 股 5000+ 只股票，支持多源回退，不访 Yahoo。
  • LLM 输出有随机性，同一只股票跑两次结果可能不同。

关于数据源 API Key

BaoStock 不需要 API Key，免费无限流，专为 A 股设计，最稳定。这是首选数据源。

AKShare（腾讯/新浪/东方财富）不需要 API Key，可以直接用。覆盖 5000+ 只 A 股，按稳定性依次回退。

选股器不用 Yahoo 兜底：海外源不可达只会返回“没数据”，与“这只票本身没数据”分不开；四个境内源都落空就记为无数据。Yahoo（yfinance）仅服务美股链路，同样不需要 API Key。

Alpha Vantage（备选数据源）：免费 Key 在 alphavantage.co 注册获取，填 ALPHA_VANTAGE_API_KEY=xxx。

FRED（宏观经济数据，可选）：免费 Key 在 fred.stlouisfed.org 注册，填 FRED_API_KEY=xxx。

运行分析：选出 3 只推荐买入股票

约 15-60 分钟（候选越多越久）

4.0 方法零：用内置选股器自动扫描全市场（最推荐 ⭐）

无需提供候选股票池，选股器会自动从 A 股全市场（5000+ 只）中扫描、四维筛选、深度分析并推荐 Top 3 股票。

🎯 五步筛选 + 交互确认 + 深度分析

  • 第一阶段：逐级筛选潜力股
  • 第 1 步：获取股票池 - AKShare 全 A 股 ~5200 只
  • 第 2 步：基础过滤 - 剔除 ST/科创板/北交所，只留主板/中小板/创业板
  • 第 3 步：资金面预筛选 - 主力净流入>0，取前 100 只（盘前自动改用最近一个交易日的净流入）
  • 第 4 步：消息面筛选 - 从资金流入前 20 板块中找出近 7 天有利好的板块，保留属于这些板块的股票
  • 第 5 步：技术指标筛选 - RSI 30-65、股价>MA20、MACD 金叉、量比≥0.8 → 几十只潜力股
  • ❓ 交互确认 - 打印潜力股列表，询问是否继续深度分析（选否则结束，--yes 跳过提问）
  • 第二阶段：深度分析找出 Top 3
  • 第 6 步：多智能体深度分析 - TradingAgents 分析引擎（每只 3-5 分钟）
  • 第 7 步：综合评分排序 - LLM 评级 40% + 技术面 30% + 资金面 20% + 动量 10%
  • 🏆 最终推荐输出 - 表格列出 Top 3 股票代码、股票名称、上涨潜力分数、综合评级
  • 📌 交易点位建议 - 每只股票一行：阻力位、支撑位、建议买入价、建议卖出价
  • 第 8 步：生成报告 - 每只推荐股落盘完整报告树（分节 md + complete_report.md/html），另存 topN 摘要

4.2 方法二：用脚本批量分析（推荐）

创建一个 Python 脚本，批量分析多只 A 股，自动对比结果：

Python analyze_astocks.py — 批量分析 A 股并排序
""" 批量分析 A 股股票，按评级排序，选出 Top 3 推荐买入。 用法：python analyze_astocks.py """ from tradingagents.graph.trading_graph import TradingAgentsGraph from tradingagents.default_config import DEFAULT_CONFIG from tradingagents.agents.rating import parse_rating from datetime import date # === 第 1 步：配置 === config = DEFAULT_CONFIG.copy() config["output_language"] = "Chinese" # 报告用中文 config["max_debate_rounds"] = 2 # 多空各 2 轮辩论 config["max_risk_discuss_rounds"] = 2 # 风控 2 轮 # === 第 2 步：定义候选股票池 === # 你可以替换为你自己关注的 A 股股票 candidates = { "600519.SS": "贵州茅台", "000858.SZ": "五粮液", "601318.SS": "中国平安", "000333.SZ": "美的集团", "600036.SS": "招商银行", "002594.SZ": "比亚迪", "300750.SZ": "宁德时代", "601012.SS": "隆基绿能", "000001.SZ": "平安银行", "600276.SS": "恒瑞医药", } # === 第 3 步：评级排序权重（从最看多到最看空）=== rating_score = { "Buy": 5, "Overweight": 4, "Hold": 3, "Underweight": 2, "Sell": 1, "REVIEW": 0, # 无法解析，排最后 } # === 第 4 步：初始化分析引擎 === today = date.today().strftime("%Y-%m-%d") ta = TradingAgentsGraph(debug=False, config=config) results = [] for ticker, name in candidates.items(): print(f"\n{'='*50}") print(f"正在分析: {name} ({ticker})") print(f"{'='*50}") try: state, signal = ta.propagate(ticker, today) # 提取评级 rating = signal # 已经是 5 级评级字符串 score = rating_score.get(rating, 0) # 提取交易决策文本 decision = state.get("final_trade_decision", "") results.append({ "ticker": ticker, "name": name, "rating": rating, "score": score, "decision": decision, }) print(f" 评级: {rating} (得分: {score})") except Exception as e: print(f" 分析失败: {e}") results.append({ "ticker": ticker, "name": name, "rating": "ERROR", "score": -1, "decision": str(e), }) # === 第 5 步：排序并输出 Top 3 === results.sort(key=lambda x: x["score"], reverse=True) print(f"\n{'#'*60}") print("# 分析结果排名（从最推荐到最不推荐）") print(f"{'#'*60}") for i, r in enumerate(results, 1): marker = " ⭐ TOP 3 推荐买入" if i <= 3 else "" print(f" {i}. {r['name']} ({r['ticker']}) → {r['rating']}{marker}") # === 第 6 步：保存 Top 3 的详细报告 === top3 = results[:3] for r in top3: ta.save_reports( {"company_of_interest": r["ticker"], **{ k: v for k, v in { "market_report": "", "sentiment_report": "", "news_report": "", "fundamentals_report": "", "investment_debate_state": {}, "investment_plan": "", "trader_investment_plan": "", "risk_debate_state": {}, "final_trade_decision": r["decision"], "final_rating": r["rating"], }.items() if v }}, r["ticker"], ) print(f"\n {r['name']} 报告已保存") print(f" 决策摘要: {r['decision'][:200]}...")
脚本说明

第 1 步：复制默认配置，设置中文输出和辩论轮数。

第 2 步：定义候选股票池。你可以自由替换为你关注的 A 股。

第 3 步：定义评级权重，Buy=5 分最高，Sell=1 分最低。

第 4 步：遍历每只股票调用 propagate()，收集评级和决策文本。

第 5 步：按评分排序，输出排名。

第 6 步：保存 Top 3 的详细报告。

5

解读结果：如何确定卖出点位

约 10 分钟

系统能给你什么？

  • 5 级评级：Buy / Overweight / Hold / Underweight / Sell
  • 交易决策文本：AI 写的完整分析报告，包含买入理由
  • 技术分析报告：包含 RSI、MACD、布林带等指标的具体数值
  • 基本面报告：财务数据、估值指标

系统不能直接给你什么？

  • 具体的目标价格（如"涨到 1800 元卖出"）
  • 止损价位（如"跌到 1500 元止损"）
  • 这些需要你根据技术分析报告中的指标自行判断

5.1 从技术分析师报告中提取卖出信号

每只股票的分析报告中，Market Analyst（技术分析师）的报告包含关键的技术指标。打开保存的 HTML 报告，找到 "Market Report" 部分，关注以下指标：

指标卖出信号具体判断
RSI（相对强弱指数）RSI > 70超买区域，股价可能回调，考虑卖出
MACDMACD 线下穿信号线（死叉）短期趋势转弱，卖出信号
布林带上轨股价触及或突破上轨短期超买，可能回落
均线系统股价跌破 20 日/60 日均线中期趋势转弱
成交量放量下跌卖压增大，考虑止损

5.2 从交易决策文本中提取关键信息

打开报告的 "Final Trade Decision" 部分，AI 通常会写类似这样的内容：

示例 AI 决策文本（示意）
Rating: Buy 贵州茅台当前技术面显示 RSI 为 45（中性偏强）， MACD 刚刚形成金叉，短期动能向上。 基本面方面，最新财报显示营收同比增长 15%， 净利润率维持在 50% 以上，估值合理。 建议在当前价位附近建仓，关注 1800 元附近的 前期高点阻力位。若突破 1800 元，上方空间 看向 1950-2000 元区间。 止损建议设在 60 日均线（约 1550 元）下方。
如何读这段文本

买入理由：RSI 45（不超买）、MACD 金叉（趋势向上）、基本面好。

阻力位/目标位：1800 元（前期高点），突破后看 1950-2000 元。

止损位：1550 元（60 日均线下方）。

注意：这些价格是 AI 根据当前数据估算的，不是保证，实际走势可能完全不同。

5.3 制定卖出策略的 3 种方法

方法操作适合场景
目标价卖出AI 报告中提到的阻力位/目标位，到达后卖出短线交易
技术指标卖出RSI > 70 或 MACD 死叉时卖出趋势交易
止损卖出跌破 AI 提到的支撑位（如 60 日均线）时卖出风险控制

再次提醒

AI 给出的价格参考不是投资建议。A 股有涨跌停限制（±10%），且受政策影响大。请结合自身风险承受能力，必要时咨询持牌投资顾问。
